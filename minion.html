Minion

Many open engines. One runtime.

Minion is not an inference engine of its own. It gathers other open-source engines — for speech, vision, language, image and video — and adds the custom logic that runs them as one local runtime, on a desktop, a server, or inside your own product.

What's inside

Other people's engines. Minion's glue.

Under the hood, Minion is a collection of existing open-source inference engines. Our contribution is the custom logic around them — loading, routing, scheduling and one API — so the app on top only has to say what it wants.

Speech

Wraps open-source speech-to-text, text-to-speech and voice-cloning engines — running on the machine, not a server.

Vision

Wraps an open-source vision engine that reads what is on screen — windows, text and controls — so the assistant can act on it.

Model

Wraps an open-source language engine for reasoning, drafting and turning intent into a plan.

Image

Wraps an open-source image engine to generate pictures from a prompt — on the machine, with no cloud round trip.

Video

Wraps an open-source video engine to generate and edit short clips locally, then drop them straight into your workspace.

Open

Every engine is open source and so is the glue. Read it, fork it, swap an engine, or ship it inside your own app.

Custom logic

Not just a bundle. Minion adds the custom logic — engine selection, scheduling, memory and a single API — that turns separate engines into one runtime.

Layers

From the microphone to the picture.

Each layer is backed by a different open-source engine, and Minion's custom logic moves the work from one to the next. You can use the whole stack, or pull out the one piece you need.

Because the layers are separate, a voice assistant, a screen reader and an image generator all run on the same foundation.

Local-first

Runs on your machine, stays on your machine.

Minion is built for home computers and desktops, not a data centre. Models download once and run locally, so your voice and your screen never have to leave the device.

No round trip

Speech, vision, language, image and video all run on-device, so results come back at the speed of your hardware.

Private by default

Your microphone and screen stay local unless you deliberately connect something.

Swap the model

Use the bundled model or bring your own. The stack underneath does not change.

For builders

Use it in your own app.

Minion is a runtime that unifies other open-source engines — not a model of its own. Use it anywhere you need a model to listen, see, understand or create — a desktop app, a server, or your own product.
