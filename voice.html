How it works

Listen, understand, act, confirm.

A microphone capture goes to speech-to-text, into a local model that turns your words into a plan, then out to the actions that plan needs — an app, a script, an API or a device.

Propane speaks back what it did, so the loop stays hands-free and you always know the state of the world.

2 · UnderstandMinion — local language model
3 · Actyour apps, scripts, APIs & devices

The SDK

Embed voice automation in your product.

Define an automation once — its trigger, its steps and its actions — and Propane Voice runs it. Ship it inside your own desktop app, appliance or service, using your own models or ours.

The Voice SDK is the same engine behind the service, so anything the service can do, yours can too.

Request SDK access
// a voice automation is a small script
import { defineVoiceAutomation } from '@propane/voice';

export default defineVoiceAutomation({
  name: 'Weekly orders',
  trigger: 'voice',
  steps: [
    (ctx) => ctx.fetch('/orders?range=week'),
    (ctx, orders) => ctx.summarize(orders),
    (ctx, summary) => ctx.email('me@company.com', summary),
  ],
});
